Project Snapshot

The project is strongest today as a CLI-first speech toolkit. Core TTS and faster-whisper dictation are implemented. GNOME custom hotkey integration is supported. GNOME Shell extension work and native distro packages remain experimental or beta.

Architecture Overview

The repo is intentionally simple: user-facing shell launchers in bin/, Python implementations in src/, and setup/release helpers in scripts/.

TTS Flow

Text CLI, file, URL, stdin
->
Engine Edge or Kokoro
->
Output Player or audio file

Dictation Flow

Mic ffmpeg capture
->
STT Core VAD + faster-whisper
->
Output Clipboard or typing

GNOME Hotkey Flow

Ctrl+Alt+V GSettings custom shortcut
->
Toggle talk2claude-faster-toggle
->
State Status JSON + clipboard

Configuration And Runtime

Important Environment Variables

  • EDGE_VOICE: default Edge TTS voice.
  • KOKORO_MODEL_DIR, KOKORO_VOICE, KOKORO_LANG: Kokoro runtime selection.
  • SAYREAD_MAXCHARS, SAYREAD_PLAYER: reader chunking and playback defaults.
  • WHISPER_MODEL, WHISPER_DEVICE, WHISPER_COMPUTE_TYPE: faster-whisper runtime.
  • ASR_LANG: speech recognition language or auto.
  • DICTATION_MODE: clipboard by default; typing is explicit opt-in.
  • DICTATION_PREVIEW=1: review/edit before output.
  • STT_TRANSCRIPT_FALLBACK=1: opt in to private latest-transcript file fallback.

State And Privacy

  • Runtime config lives in ~/.config/linux-speech-tools/install.env with private permissions.
  • Dictation runtime state uses XDG runtime/state locations.
  • Dictated text is not printed into hotkey logs.
  • Fallback transcript files are disabled unless explicitly enabled.
  • talk2claude-faster-toggle purge-state removes stopped STT state, logs, status, and fallback files.
